The Problem

Vulnerabilities often slip past manual code reviews straight to production. Traditional security scanners output massive, unreadable JSON logs, causing alert fatigue and slower remediation times.

The Solution

Sentinel runs directly in your local terminal or CI/CD pipelines. It utilizes standardized security protocols offline, or Mistral AI / Ollama online, to explain raw security risks and apply safe, one-click code remediations.

SQL Injection (CWE-89)

Concatenating untrusted user inputs directly into SQL query strings.

Offline Remediation Protocol:

Protocol: Parameterized Queries. Replace string concatenation or formatting inside SQL executions with placeholders and pass query parameters as a tuple. Example: Change cursor.execute(f'SELECT * FROM users WHERE username = "{user}"') to cursor.execute('SELECT * FROM users WHERE username = ?', (user,)).

Vulnerable Code
# Unsafe SQL Construction
def get_user(user_id):
    query = f"SELECT * FROM users WHERE id = {user_id}"
    return db.execute(query)

Built-in Capabilities

Sentinel combines multiple scanner paradigms and AI to automate application hardening.

🔍

Static Analysis (SAST)

Analyzes AST structures to catch SQLi, XSS, commands, secrets, and weak cryptosystems in Python, JavaScript, and TypeScript.

📦

Dependency Audit (SCA)

Audits dependencies in `requirements.txt`, `package.json`, and `go.mod` against OSV/NVD with local SQLite speed caching.

🕸️

Dynamic Analysis (DAST)

Crawls live web apps to test routes for parameter injection vulnerabilities and missing headers (CSP, HSTS, X-Frame-Options).

🤖

AI Auto-Fix Engine

Connects to Mistral Cloud or a local Ollama server to write secure code patches. Maps issues to remediation standards offline.

⚙️

Advanced CLI Subcommands

Initialize scanning config with `sentinel init`, manage cached vulnerabilities with `sentinel update-db`, or refine scans via command arguments.

🚀

CI/CD Pipeline Ready

Fail pipeline builds via severity rules (`--fail-on`), auto-apply security fixes, and output report logs in JSON, SARIF, or HTML format.
